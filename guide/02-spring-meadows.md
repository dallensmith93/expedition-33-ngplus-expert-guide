# Clair Obscur: Expedition 33 — Part 2 — Spring Meadows

## EPISODE GOAL

100% Spring Meadows on the first visit except Paint Spike rooms. Jar lives. Eveque dies. Mime gives the Baguette set.

## STARTING POINT

Spring Meadows landing. Gustave alone after the massacre cinematic.

## BEFORE WE START

- Expert + NG+: Lancelier tutorial still teaches shot / parry. Do not skip the first fight if you want the free catalysts.
- White Nevron rule for the whole run: **help, take the reward, do not kill.** Blanche (Episode 23) pays 100 Colour of Lumina for a clean sheet.

---

## WALKTHROUGH

### FROM: Spring Meadows start

☐ Face the waterfall on your right. Pick up **180 Chroma**.

☐ Walk the only path up.

# NEW ENEMY — Lancelier

**Weakness:** Ice (later, when Lune is in).  
**Important Attack:** linear thrust.  
**Important Drop:** Chroma Catalyst x2 from the tutorial kill.  
**Monoco Skill:** Lancelier Impale (Episode 13 return).

☐ Grapple when taught. Climb expedition pegs when taught.

☐ After the cave cinematic, fight the **Portier**. Lune joins mid-fight.

# PICTO — Dodger

**Effect / Lumina:** Gain 1 AP on Perfect Dodge, once per turn.  
**Exact Location:** Portier reward.  
**Recommended Characters:** everyone.  
**NG+ Expert Use:** keep it as a Lumina. The Picto slot is better used on damage later.

☐ Exit the cave into the river meadow.

### FROM: Meadows Corridor Expedition Flag

☐ Activate the flag. Rest. Assign Lune Ice and a heal.

☐ Continue the main path. The game teaches **Backstrike**. Ambush the Lanceliers.

# WEAPON — Lanceram (Gustave)

**Character:** Gustave (later Verso)  
**Element:** Physical  
**Obtained From:** Lancelier pack after Meadows Corridor  
**How to Obtain:** win the Backstrike fight  
**NG+ Expert Note:** if you already own a better Verso/Gustave weapon, this is an upgrade/chroma convert. Equip only if it actually wins.

☐ After Lanceram, walk right up the small hill. **180 Chroma**.

☐ A few steps forward, small right spur. **Critical Burn**.

# PICTO — Critical Burn

**Effect:** bonus crit chance vs Burned targets.  
**Nearest Flag:** Meadows Corridor  
**Recommended Characters:** Gustave (Overcharge) / Lune (Fire later).

☐ Return to the main path. Lancelier in the field. Take the **left** spur first. **180 Chroma**. Return.

☐ Fight the pair of Lanceliers. Enter the house.

☐ Right side of the room: **Chroma Catalyst**.

☐ Up one floor. Magical rope up.

☐ On landing, immediate right: hidden alcove **Energy Tint Shard**.

☐ Through the nearby "door" before going back up: **360 Chroma**.

☐ Resume the upward path toward the next flag.

### FROM: Grand Meadow Expedition Flag

☐ Activate the flag.

☐ Drop left off the approach for **180 Chroma** near crates. Climb back.

# FROM: Grand Meadow — Mime first

☐ Do **not** take the right path to the large Portier yet.

☐ Left path. Smaller enemy + **180 Chroma**.

☐ Look out for the distant grapple. Grapple. Linear platforms.

# MIME — Spring Meadows

**Type:** Optional  
**Nearest Flag:** Grand Meadow  
**Reward:** **Baguette Outfit + Baguette haircut (Gustave)**  
**NG+ Expert Strategy:** Comfortable. Same wall/Break rules as Lumière.

☐ Return to Grand Meadow.

☐ Right of the flag: large Portier. Kill it. **Colour of Lumina** behind it.

☐ Mount the platform behind the Portier. Main path.

☐ Flying-enemy tutorial. Reward: **Chroma Catalyst x2**.

# FROM: Grand Meadow / post-fly tutorial — Chromatic first

☐ You will see a magical rope up. **Do not take it yet.**

☐ Go right to the **Chromatic Lancelier**.

# BOSS — Chromatic Lancelier

**Type:** Chromatic  
**Weakness:** Ice  
**Dangerous Attacks:** long thrust strings.  
**Recommended Party:** Lune + Gustave  
**Recommended Skills:** Lune Ice; Gustave Overcharge on Break.  
**Reward:** Lanceram upgrade, **Augmented Attack**, Chroma Catalyst x2, Colour of Lumina x5  
**NG+ Expert Strategy:** Comfortable if Cheater/Painted Power carried over. Otherwise Strong Build — do not get greedy.

# PICTO — Augmented Attack

**Effect:** stronger base attack.  
**How to Obtain:** Chromatic Lancelier.

☐ Behind the Chromatic: **180 Chroma**.

☐ Now take the magical rope up.

☐ At the top, left instead of the main right path. Drop ledges: **720 Chroma**.

☐ Back to the glowing tree. Left grapple. Continue to a split.

☐ Split: **right** first. Portier. **Chroma Catalyst x2**. Dead end **180 Chroma**. Return.

☐ Main path. Climb the mountain handholds. Cave.

☐ Cutscene with Lune and Jar. **JOURNAL — Expedition 81** is automatic.

## BUILD CHECK

### Gustave
Weapon: best carried-over Verso/Gustave weapon, or Lanceram if it won the comparison.  
Skills: Lumière Assault, Overcharge, Marking Shot if you have it.  
Pictos: Dodger or a carried HP/Speed Picto.  
Luminas: Cheater, First Strike, Painted Power if owned.

### Lune
Weapon: best carried Fire/Ice weapon, or Lighterim.  
Skills: Ice, a heal, Thermal Transfer if you already know it.  
Luminas: same carry package.

**Why:** Eveque and the Chromatic are Ice checks. Expert still one-shots you if you eat a full string.
