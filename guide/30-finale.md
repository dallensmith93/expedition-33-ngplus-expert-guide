# Clair Obscur: Expedition 33 — Part 30 — Finale

## EPISODE GOAL

Return to Lumière. Walk the story path. Pick up the four things that only exist here. Finish the game.

This is not a cleanup episode. If you are missing Continent content, go back to Episode 29.

## STARTING POINT

Continent, Lumière portal. Episode 29 audit green.

## BEFORE WE START

- Monoco in the party for Aberration Light and Creation Void.
- If you found Trash-can Man in Episode 1, watch for him in this district.
- 1.5.0 Old Key sits somewhere in this finale area if you still need it. You should not.
